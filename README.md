# DashBoard Financeiro 2027

Template Notion de controle financeiro pessoal, em preparação para venda em 2027.

## Conteúdo do repositório

```
export/     Export do Notion (markdown + CSVs das bases)
AUDITORIA.md  Auditoria de prontidão para venda
```

## Estrutura do template

Página principal **DashBoard Financeiro 2027**, com:

- **Guia Inicial** — boas-vindas, rotina recomendada (diária/semanal/mensal) e regras de uso
- **Menu Financeiro** — banco de navegação com controle de visibilidade por item
- **Detalhamento Mensal** e **Resumo Mensal**
- **Cartões de Crédito** — limite, fechamento, vencimento, fatura do mês e do próximo
- **Metas / Investimentos** — objetivo, aportes, progresso
- **Dívidas** — parcelamento, valor pago, progresso

Módulos previstos no menu: Dívidas, Cartão de Crédito, Despesas, Entrada,
Investimentos e Metas, Planejamento de Gastos, Configurações Iniciais.
